JLPT Master — Learner App · Design Review

Mobile-first prototype (375px) of the 9 learner screens plus 1280px versions of Home, Mock test lobby and Exam taking. Tokens, type, chips, switches and nav patterns are the same as the Admin CMS review (docs/design/admin-cms). All data is mock data. Nothing here calls the API or the database.

Primary indigo #3730A3Accent vermilion #C0331BCards 16px · controls 12px · 8px gridTouch targets ≥ 48pxLight mode only
The Furigana and VI / EN controls in any top bar are live. They change every frame on this page. EN covers navigation and the main headings only.

Mobile · 375px

Screens 1–9 in order. Bottom tab bar: Trang chủ · Học · Thi thử · Kanji · Hồ sơ. The lesson and exam flows run in focus mode, without the tab bar.
