# JLPT Master — Responsive Wireframe Blueprints

**Document:** `docs/wireframes.md`  
**Phase:** 2 — UI/UX Design (`ui-ux-designer`)  
**Status:** Under Review (Gate Approval Required)  

---

## 1. Overview & Viewport Standards
All wireframes are specified for two primary reference environments:
- **Mobile Viewport:** 375px width (iPhone standard base), single-column stacked hierarchy, sticky bottom navigation bar, minimum 44px touch targets.
- **Desktop Viewport:** 1440px width (Modern desktop monitor), 260px fixed left navigation sidebar, 1140px main content canvas with multi-column grid layouts.
