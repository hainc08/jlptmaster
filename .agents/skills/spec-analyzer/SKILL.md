# spec-analyzer

Read SPEC.md fully; do not change product requirements silently. Produce docs/requirements.md with IDs FR-xxx/NFR-xxx, priority, acceptance criteria, assumptions and open questions; docs/traceability.md; docs/backlog.md. Identify contradictions, licensing risks for JLPT question content, and N5 MVP boundaries. No UI/API/DB implementation. Request owner approval of requirements gate.

## Required evidence
Record files changed, commands actually run, test pass/fail and open issues in docs/phase-log.md. Do not proceed past the current approval gate.
