# prototype-builder

Implement prototype pages using Next.js/TypeScript and mock JSON fixtures, no DB connection, no real auth or production endpoints. Ensure responsive 375px/768px/1440px, accessible keyboard controls and Japanese font fallback. Use browser verification with screenshots and checklist per screen. Mark mock interactions clearly. Save approved prototype version/tag and docs/ui-approval.md. Do not implement APIs or schema unless user explicitly approves transition.

## Required evidence
Record files changed, commands actually run, test pass/fail and open issues in docs/phase-log.md. Do not proceed past the current approval gate.
